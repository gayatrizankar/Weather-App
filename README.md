# 🌦️ Weather App

A sleek and simple weather app that shows real-time weather data using the OpenWeather API.

---

## 🚀 Features

- 🌍 Search weather by city
- 🌡️ Real-time temperature, humidity, and conditions
- 🧭 Wind speed and direction
- 🌓 Dynamic icons and background changes
- 📱 Fully responsive UI
- 💻 Built using vanilla JavaScript or React

---

## 🛠️ Tech Stack

- HTML, CSS, JavaScript (Vanilla or React)
- OpenWeatherMap API
- Optional: Tailwind CSS or Bootstrap
